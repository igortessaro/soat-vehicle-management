# soat-vehicle-management

Serviço principal da plataforma de revenda de veículos. Este repositório será responsável pelo cadastro e pela edição dos veículos, além de manter o banco de dados oficial dos dados cadastrais.

As decisões de escopo, domínio, arquitetura e organização do trabalho estão documentadas em [docs/PROJECT-DEFINITION.md](docs/PROJECT-DEFINITION.md).
